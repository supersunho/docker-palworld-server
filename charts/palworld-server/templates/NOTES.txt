Palworld Dedicated Server has been deployed!

1. **Get the admin password:**

   {{- if .Values.server.existingSecret }}
   Retrieved from the existing Secret `{{ .Values.server.existingSecret }}`:
   kubectl get secret {{ .Values.server.existingSecret }} \
     -o jsonpath="{.data.{{ .Values.server.adminPasswordKey }}}" | base64 -d
   {{- else }}
   A Secret `{{ include "palworld-server.fullname" . }}-password` was auto-generated.
   Retrieve the password with:
   kubectl get secret {{ include "palworld-server.fullname" . }}-password \
     -o jsonpath="{.data.{{ .Values.server.adminPasswordKey }}}" | base64 -d
   {{- end }}

2. **Connect to the server:**
   Game port: {{ .Values.service.gamePort }} (UDP)
   Query port: {{ .Values.service.queryPort }} (UDP)

   {{- if .Values.managementService.enabled }}
   REST API: port {{ .Values.managementService.restApiPort }} (TCP)
   RCON:     port {{ .Values.managementService.rconPort }} (TCP)
   {{- end }}

3. **Monitoring:**
   {{- if or (eq .Values.monitoring.mode "prometheus") (eq .Values.monitoring.mode "both") }}
   Prometheus metrics / dashboard available on port {{ .Values.monitoring.dashboardPort }} (dashboard service)
   {{- end }}

4. **Use your own Secret (optional):**
   To use a pre-created Secret instead of the auto-generated one:
   kubectl create secret generic palworld-admin-password \
     --from-literal=admin-password=YOUR_STRONG_PASSWORD

   Then install with:
   helm install my-release . --set server.existingSecret=palworld-admin-password
